Changed: UE4SS is no longer required. Squad limits, the six-model lineup, nameplates, holotable range and deployment logic now run in a Game Feature pak.
Changed: Upgrade support for v1 installations. The download retains the existing Core container filenames and includes a harmless main.lua stub with the original runtime manifests so mod managers can replace the previous runtime.
Changed: Three-operator missions now allow six: Not Your Turf, Dantooine 025 and Kaller 030. Bespin remains solo and the opening tutorial keeps its authored squad.
Fixed: Fixed the build-version installation block. Build 25898267 is now included in the compatibility manifests; managers previously rejected it because only older builds were declared. This corrects the install check, not a separate gameplay issue.
Fixed: Better cover selection. Added a wider local grid and searches along cover lines to find free cover beside occupied spots, while keeping the facing-cover rules.
Fixed: Late-loading encounter cover. Distant areas are prepared as the squad approaches, so later encounters can use cover that was not available at mission start. Confirmed with all six operators in cover in Belly of the Beast's second encounter.
